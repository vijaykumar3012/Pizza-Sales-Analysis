# Pizza-Sales-Analysis

**Pizza Sales Analysis Using Python | Data Analytics Project**

I’m happy to share my latest Data Analytics project: **Pizza Sales Analysis using Python.**

In this project, I explored pizza sales data to understand customer preferences, sales performance, and ordering patterns.

I used Python libraries like Pandas, Matplotlib, and Seaborn to clean, analyze, and visualize the data.

**Some interesting business insights I discovered:**

- Classic pizzas contributed the highest sales share at 26.9%.
- Supreme pizzas accounted for 25.5% of sales.
- Friday recorded the highest revenue among the days shown.
- Customer orders peaked around 12 PM and 1 PM.
- The Classic Deluxe Pizza was the most ordered pizza, with 2,329 orders.
